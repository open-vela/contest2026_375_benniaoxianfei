# 面向听障群体的端侧静态手语手势翻译终端

> 2026 openvela AI 硬件开发者大赛 · 队伍：benniaoxianfei（375）
> 基于 **ESP32-P4-Function-EV-Board + OpenVela** 的端侧 AI 应用

## 一句话简介

摄像头采集静态手语手势 → 端侧 AI 识别为文字 → 屏幕显示 + 语音播报，
帮助听障人士完成简易日常沟通。全程端侧推理，无云端依赖。

## 核心功能（5 项）

| # | 功能 | 技术方案 |
|---|------|---------|
| 1 | 手势识别（12 类） | TFLite Micro + INT8 轻量 CNN（CPU 端侧推理） |
| 2 | 屏幕实时显示 | LVGL（MIPI-DSI 7 寸屏，预览+结果叠加） |
| 3 | 语音播报 | 预合成 WAV，I2S + ES8311 codec 播放（不做端侧 TTS） |
| 4 | 日志上传 | WiFi（ESP32-C6）/ 有线网 → HTTP POST JSON → 网页查看 |
| 5 | 触摸配置 | 模式切换（数字/字母/词）+ 置信度阈值调节 |

## 技术亮点

- **BSP 移植**：OpenVela 官方不支持 ESP32-P4，自行完成芯片层/板级层/HAL 适配
  移植（修复 10+ 处 HAL 与 OpenVela 的 API 差异），**固件编译成功（591KB）**
- **端侧 AI**：轻量 CNN + INT8 量化（模型 303.8KB），400MHz 双核 RISC-V 推理；
  **量化一致性修复**（Rescaling 输入域统一）后 **INT8 精度 95.0% = 浮点水平**
- **模拟器先行验证**：应用已在 OpenVela goldfish 模拟器跑通
  （LVGL 界面实时刷新 + SIM 识别轮换，见 `模拟器截图_手语翻译UI_1/2.png`）
- **降级预案**：日志本地持久化 + 有线网兜底，WiFi 不通不影响主流程

## 运行方式

### 编译固件（Ubuntu 22.04 虚拟机）
```bash
# 详见 开发进度日志.md 第十二/十三节；HAL 已修复并打包
bash build_p4_final.sh        # 产物: nuttx.bin
```

### 烧录（Windows）
```bash
pip install esptool
esptool.py -c esp32p4 -p COM3 -b 460800 write_flash 0x0 nuttx.bin
```

### 使用
1. 板子上电 → 串口 115200 出现 `nsh>`（里程碑 M1）
2. 运行 `sign_translate` 启动应用
3. 摄像头对准手势 → 屏幕显示识别结果 + 语音播报
