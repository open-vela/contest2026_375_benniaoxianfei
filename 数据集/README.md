# 数据集目录说明

```
数据集/
├── raw/          ← 原始素材放这里（照片 jpg/png 或视频 mp4），按类别文件夹
│   ├── 0_零/
│   ├── 1_一/
│   ├── ...
│   ├── 9_九/
│   ├── 你好/
│   └── 谢谢/
├── train/        ← 由 prepare_dataset.py 自动生成（增强后训练集）
└── val/          ← 由 prepare_dataset.py 自动生成（验证集）
```

## 使用方法

1. **拍素材**：手机拍照片或视频，放进 `raw/<类别>/`
   - 每类目标 ≥150 张（视频最省力：每类拍 1 个 15 秒视频，脚本自动抽帧）
   - 手势占画面 1/3~1/2，背景 2-3 种，光线自然光+台灯各一半
2. **处理**：`python 训练脚本/prepare_dataset.py` → 抽帧/缩放/增强/切分
3. **训练**：`python 训练脚本/train_cnn.py` → 出 INT8 模型

> raw 里的原始素材体积大，不入 Git 仓库（train/val 为生成物也不入）；
> 仓库只跟踪本说明。数据完整版自行备份（网盘/移动硬盘）。
